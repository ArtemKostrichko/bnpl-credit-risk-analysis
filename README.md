# BNPL Credit Risk Analysis

Exploratory analysis of customer default risk in Buy Now, Pay Later transactions.

## Project overview

The project analyzes a synthetic BNPL dataset containing 10,345 observations and 17 variables. The analysis includes data-quality checks, descriptive statistics, visualizations, feature transformation, customer-group comparisons, and statistical hypothesis testing.

## Key findings

- The overall default rate is 39.05%.
- The High Risk segment has the highest default rate.
- Default is associated with higher risk scores, repayment delays, missed payments, and debt-to-income ratios.
- Higher credit scores and monthly income are associated with lower default rates.
- Three customer-risk hypotheses were tested using Welch’s two-sample t-test.
